# KokurikulerSMK - Sistem Feedback Kokurikuler SMK

Platform web evaluasi dan pengumpulan feedback kegiatan kokurikuler SMK berbasis PHP PDO dan MySQL.

## Fitur
- Inisialisasi otomatis skema database dan tabel via PDO
- Form kuisioner feedback siswa interaktif
- Dashboard rekapitulasi data penilaian hasil kegiatan

## Setup
1. Pastikan server web Apache dan MySQL aktif di Laragon.
2. Akses `index.php` melalui browser.
3. Database `feedback_stepup_v2` akan dibuat otomatis saat pertama kali diakses.
